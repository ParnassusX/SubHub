# SubHub Backend

This directory contains the Node.js Express backend for the SubHub application.

## Prerequisites

- Node.js (v14 or later recommended)
- npm

## Setup and Running

1.  Navigate to the `backend` directory:
    ```bash
    cd backend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the server:
    ```bash
    npm start
    ```
The server will start on port 3001 by default. The SQLite database file (`db.sqlite`) will be created in this directory.
