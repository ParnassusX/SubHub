# SubHub Frontend (React + Vite)

This directory contains the React.js frontend for the SubHub application, built with Vite and styled with Tailwind CSS.

## Prerequisites

- Node.js (v14 or later recommended)
- npm

## Setup and Running

1.  Navigate to the `frontend` directory:
    ```bash
    cd frontend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
The development server will typically start on port 5173.
